**BirdCLEF 2025 (38ᵉ place, médaille d'argent)** : Points clés : prétraitement audio minutieux, augmentation de données, pseudo-étiquetage et distillation de modèle.
- 3 étapes d'entraînement:
  1. FocalLoss, Adam, Cosine Annealing + warmup sur données de base.
  2. Ajout des pseudo-étiquettes et première auto-distillation.
  3. Mélange 50% données étiquetées / 50% non étiquetées avec pseudo-étiquettes + 2ᵉ distillation.
- Stack de 13 EfficientNets (4 × v2_s, 3 × v2_b3, 4 × b3_ns, 2 × b0_ns).

**Architectures Récurrentes dans le Top 5 :**
- **Modèles CNN** : EfficientNet-B0/B3, NFNet, SE-ResNeXt50, ResNet34
- **Modèles temporels** : Conformer pour la modélisation temporelle
- **Représentations** : Spectrogrammes Mel et log-Mel avec et sans bruit
- **Pooling** : Multi-head self-attention pooling, GeM pooling
- **Fonctions de perte** : Focal Loss (gestion du déséquilibre des classes)
- **Optimisation** : AdamW avec warmup et cosine annealing
- **Validation** : 5-fold stratified cross-validation avec TTA (test-time augmentation)
- **Augmentations** : SpecAugment, mixup additif
- **Prétraitement Audio** : Nettoyage manuel des commentaires vocaux et des artefacts pour les classes rares
- **Pseudo-étiquetage** : Essentiel ; itérations et distillation pour propager les labels sur les données non étiquetées

## 🏆 Phase 3 : Fusion et Notebook Ultime

Voici le pipeline de fusion que je propose, intégrant les meilleures pratiques identifiées :

### Plan Stratégique du Pipeline

```
Données Audio Brutes
→ Prétraitement Audio (nettoyage, segmentation 5s)
→ Extraction de Caractéristiques (spectrogrammes log-mel 224x224)
→ Modèles de Niveau 1 (EfficientNet-B3, NFNet, SE-ResNeXt50, Conformer)
→ Pseudo-étiquetage des Paysages Sonores Non Étiquetés
→ Augmentation des Données d'Entraînement
→ Entraînement des Modèles de Niveau 2 (EfficientNet-B0, EfficientVit-b0, MnasNet-100)
→ Stacking / Moyenne Pondérée
→ Conversion ONNX et Optimisation CPU
→ Soumission Finale
```

### Détail de la Fusion

**1. Fusion Précoce des Caractéristiques :**
- Extraction de spectrogrammes log-mel (taille 224x224 pour compatibilité avec les CNN pré-entraînés sur ImageNet utilisés dans les solutions gagnantes).
- Normalisation et éventuellement concaténation de plusieurs représentations (Mel, MFCC, delta).

**2. Fusion Intermédiaire :**
- **Bagging** : Plusieurs folds (5-fold stratified) pour chaque architecture de modèle de niveau 1.
- **Stacking hétérogène** : Combiner des probabilités de modèles différents (EfficientNet, NFNet, Conformer) via une couche de méta-apprentissage (régression logistique). La diversité est cruciale, comme le montre l'équipe CPMP en 2024.
- Utiliser un **pooling d'attention** pour agréger les caractéristiques temporelles avant la classification finale.

**3. Fusion Tardive :**
- **Distillation de connaissance** : Utiliser le modèle de niveau 1 (plus gros) comme professeur pour entraîner le modèle de niveau 2 (plus léger), comme dans les solutions 2024 et 2025.
- **Ensemble final** : Moyenne pondérée des probabilités de tous les modèles de niveau 2, éventuellement optimisée via validation croisée sur les données de validation.
- **Calibration** : Ajustement Platt ou isotonique pour améliorer l'AUC.

**4. Gestion du Pseudo-Étiquetage :**
- Générer des pseudo-étiquettes pour les 700 fichiers audio de test avec le modèle niveau 1 le plus performant.
- Ajouter ces échantillons pseudo-étiquetés aux données d'entraînement en quantité équilibrée (50/50 étiquetés/non étiquetés), comme dans la solution 2025.
- Itérer : réentraîner les modèles niveau 2 avec ces données enrichies et répéter si nécessaire.

## 📊 Points Clés de Succès

En synthèse, les éléments qui feront la différence sont :

1. **Qualité du prétraitement** : Nettoyer manuellement les données (voix humaines, silences, artefacts), en particulier pour les classes rares.
2. **Pseudo-étiquetage itératif** : C'est le facteur n°1 de gain dans les solutions 2024 et 2025.
3. **Diversité des architectures** : Combiner EfficientNet, NFNet, SE-ResNeXt et Conformer pour une fusion robuste.
4. **Distillation de connaissance** : Permet de compresser un gros ensemble en un modèle léger et rapide pour respecter la contrainte CPU.
5. **Augmentations adaptées** : SpecAugment + mixup additif, en évitant les augmentations temporelles excessives qui ont nui aux performances dans l'édition 2025.
